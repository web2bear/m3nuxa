# Прототип чтения закреплений «Пуска» Windows 11

Эксперимент только читает `start2.bin` текущего пользователя и выводит JSON с папками, их элементами и исходными идентификаторами в порядке файла. Он не меняет Windows и не импортирует конфигурацию m3nuxa. Формат является внутренним и может измениться после обновления Windows. JSON содержит сведения об установленных приложениях и пользовательских путях.

```powershell
# Вывод JSON в консоль:
./tools/StartMenuPrototype/Read-StartPins.ps1

# Создание нового файла; существующий файл не перезаписывается:
./tools/StartMenuPrototype/Read-StartPins.ps1 -OutputPath "$env:TEMP\start-pins-preview.json"

# Чтение заранее подготовленной копии:
./tools/StartMenuPrototype/Read-StartPins.ps1 -InputPath 'C:\Temp\start2-copy.bin'
```

Папки имеют `kind: folder`, имя `name` и массив `items`; остальные элементы имеют `kind: app` и исходный `id`. Это диагностический формат, не конфигурация m3nuxa. Идентификаторы `W~` могут включать GUID известной системной папки и путь к исполняемому файлу; `P~` могут содержать идентификатор пакетного приложения. Для реализации импорта ещё нужно сопоставить эти идентификаторы с ярлыками, названиями и значками, включая случаи неоднозначности.

Прототип использует код расшифровки проекта [Start2Tool](https://github.com/wwobbiee/Start2Tool) (снимок `f6177adad483c242811d7c32e4a57ce326ab05fd`). Его лицензия приведена в `LICENSE-Start2Tool.txt`. Функции записи и восстановления Windows из проекта не использованы.
