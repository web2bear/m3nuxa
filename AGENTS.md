# Запуск и визуальные проверки

- Открывай ContexWin и тестовые окна на втором мониторе, если он подключён. Перед проверкой определи расположение экранов и перенеси окна в рабочую область второго монитора; проверь положение после запуска. Если доступен только один экран, используй его и сообщи об этом пользователю.
- После запуска обычного редактора для проверки выполни `./tools/Move-TestWindow.ps1`; для другого процесса передай `-ProcessName`. Автоматическое окно `ContexWin.Editor.Checks` само выбирает дополнительный экран.
