# Состав portable-дистрибутива

Ревизия 16 ноября 2026: опубликованный GitHub Release `v0.7.0` (x64) и чистая локальная сборка исходников `0.7.5`. Архив `v0.7.0` создан до появления стартового меню. Изменение версии в исходниках и слияние PR сами по себе не создают GitHub Release: workflow запускается при отправке тега `v*`.

В скачанном архиве `v0.7.0` нет пользовательского `config.json`, каталога `configs`, логов или резервных копий. После запуска приложение создаёт собственные настройки и каталог конфигураций рядом с EXE. В исходниках `0.7.5` при первом запуске с пустым каталогом конфигураций создаётся стартовое меню; существующая конфигурация не заменяется.

Чистая x64-сборка после исправления содержит 2212 файлов, около 252 МиБ без сжатия:

| Состав | Назначение |
|---|---|
| `m3nuxa.App.exe`, `m3nuxa.Editor.exe`, их DLL и PRI | Приложение, редактор и ресурсы интерфейса. |
| 423 корневые DLL и 46 WinMD | Автономная среда .NET, ASP.NET Core для MCP, Windows App SDK и зависимости приложения. |
| `*.deps.json`, `*.runtimeconfig.json` | Служебные файлы запуска двух приложений .NET, не пользовательские настройки. |
| `workloads*.json`, `NpuDetect`, `RestartAgent.exe` и ресурсы Windows App SDK | Файлы, включённые зависимостями SDK. Их необходимость по отдельности не проверена; удаление без проверки может нарушить работу на другой системе или архитектуре. |
| `icon-packs` (1713 файлов) | Встроенный каталог Boxicons и Fluent, изображения, исходники и лицензии. |
| `en-us`, `ru-RU` | Ресурсы поддерживаемых языков. |
| Два PDB, `createdump.exe` | Диагностические файлы опубликованной .NET-сборки. |

В `v0.7.0` присутствовали лишние языковые каталоги `ca-Es-VALENCIA`, `pa-IN`, `quz-PE`, `zh-CN` и `zh-TW`: прежняя очистка не распознавала их имена. Скрипт публикации теперь проверяет имена культур и удаляет только каталоги с известными файлами MUI Windows App SDK; обнаружение постороннего содержимого останавливает сборку. Релизный workflow использует существующий `publish-local.ps1` и проверяет чистый каталог, версию и отсутствие пользовательских данных до упаковки.

Проверены сборка и состав отдельных каталогов x64, x86 и ARM64; запуск на другом ПК и на устройствах x86/ARM64 не проверен. Размер и число файлов зависят от версий SDK и зависимостей. Локальная папка `dist/m3nuxa` может содержать данные пользователя и не является чистым релизным каталогом.
