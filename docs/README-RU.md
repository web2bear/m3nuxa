# m3nuxa

Персональное меню быстрых действий для Windows 11: любимые папки, программы, скрипты и текстовые заготовки под рукой. Вызовите меню у курсора сочетанием клавиш; левый клик по значку в трее открывает редактор.

## Что умеет

- **Открывать папки и запускать программы** с заданными аргументами и рабочей папкой.
- **Запускать BAT, CMD и PowerShell-скрипты** с параметрами, видимой или скрытой консолью.
- **Отправлять сочетания клавиш и вставлять текстовые заготовки** в окно, из которого вызвано меню.
- **Копировать и перемещать выделенные в Проводнике файлы и папки** в заранее выбранные места. Для файловых операций предусмотрены прогресс, отмена и обработка совпадающих имён.
- **Собирать последовательности шагов** с задержками, ожиданием программ, текстовым буфером и отменой выполнения.
- **Организовывать действия во вложенные группы** с иконками и разделителями. Группе можно назначить сочетание для открытия её подменю, действию — для прямого запуска.
- **Открывать панель запуска** с тем же деревом в виде сетки по отдельному настраиваемому сочетанию. По умолчанию оно не задано; поиска в панели пока нет.
- **Настраивать меню в визуальном редакторе**: добавлять программы, скрипты, ярлыки и папки перетаскиванием, менять порядок пунктов, дублировать их, отменять и повторять правки.
- **Импортировать содержимое выбранной папки** с предпросмотром; вложенные папки можно добавить как группы или как действия открытия. Для пунктов доступны системные значки, изображения и разноцветные иконки Boxicons.
- **Редактировать меню через AI-агента по MCP**: читать дерево, готовить и проверять изменения, применять их с резервной копией.

## Для каких задач

Соберите рабочие инструменты в одном месте: например, группу проекта с папкой исходников, IDE и скриптами запуска. Вынесите часто используемые команды приложений и текстовые ответы в отдельные пункты. Создайте действия для раскладывания выбранных файлов по рабочим папкам без повторного поиска назначения.

Приложение работает в трее. Конфигурации меню хранятся по умолчанию в каталоге `configs` рядом с приложением; каталог можно задать параметром `--config-dir` или переменной `M3NUXA_CONFIG_DIR`. Общие настройки находятся в `m3nuxa.App.config` рядом с приложением. Portable-папку можно переносить между компьютерами; пути к внешним программам и папкам нужно учитывать при переносе.

## Установка и первый запуск

Требуется **Windows 11**. Для готовой автономной portable-сборки отдельная установка .NET не нужна.

1. Поместите всю папку portable-сборки в каталог, доступный для записи.
2. Запустите `m3nuxa.App.exe`. Редактор `m3nuxa.Editor.exe` должен находиться в той же папке.
3. Откройте меню сочетанием **Ctrl+Alt+Space**. Левый клик по значку в трее открывает редактор, правый — служебное меню.
4. Добавьте или измените пункты в редакторе и нажмите **«Применить»**.

При первом запуске с пустым каталогом конфигураций текущая версия исходников создаёт начальное меню с папками и программами Windows, а также сочетаниями для окон, виртуальных рабочих столов, снимков экрана и журнала буфера. Его можно редактировать. Существующие конфигурации при обновлении сохраняются: в уже заполненный каталог начальное меню автоматически не добавляется. Возможности опубликованных выпусков могут отличаться от текущих исходников.

Сочетания вызова и оформление меняются в свойствах выбранной конфигурации меню; открыть их можно выбором корня дерева. Язык, положение и размер панели и состояние MCP относятся ко всему приложению и хранятся отдельно от конфигураций меню. Язык выбирается в меню трея; открытый редактор нужно перезапустить. Доступны English и Русский; по умолчанию выбран английский. Автозапуск включается в служебном меню трея. Перед применением конфигурации создаётся резервная копия; хранятся десять последних версий.

## Сборка из исходников

На Windows установите **.NET 10 SDK**, скачайте или клонируйте репозиторий и выполните PowerShell-команду из его корня:

```powershell
.\publish-local.ps1
```

Скрипт соберёт автономную Release-версию для x64 в `dist/m3nuxa/` и запустит приложение. Переносить нужно эту папку целиком.

Для другой архитектуры:

```powershell
.\publish-local.ps1 -RuntimeIdentifier win-x86
.\publish-local.ps1 -RuntimeIdentifier win-arm64
```

**Перед повторной сборкой сохраните правки в редакторе:** скрипт останавливает запущенные App и Editor, а после успешной публикации запускает новый App.

## Текущие ограничения

Получение выделенного текста из сторонних приложений пока не включено. Вставка заранее заданного текста поддерживается, но подстановка `selectedText` возвращает ошибку отсутствующего контекста. Работа с выделением Проводника, возврат фокуса и открытие нового окна Проводника требуют проверки в вашей среде Windows 11.
