# Требования к контекстному лаунчеру Windows

Дата: 21 октября 2026 года. Статус: решения трёх раундов согласованы пользователем. Программная реализация и технические эксперименты ещё не выполнены.

История и уточнения: [дерево решений](REQUIREMENTS_REVIEW.md), [материалы обсуждения](PRODUCT_DISCOVERY.md). Термины: [словарь](CONTEXT.md).

## 1. Назначение и границы

Приложение заменяет используемые сценарии Quick Access Popup: открытие папок, запуск программ и скриптов, отправку сочетаний клавиш, копирование и перемещение выделенных объектов Проводника. Меню удобно настраивать в компактном редакторе и через AI-агента.

**PL-01. Платформа.** Первая версия предназначена для Windows 11 и разрабатывается на C#/.NET без зависимости от AutoHotkey.

**PL-02. Поставка.** Portable-приложение без обязательного установщика. Каталог конфигураций по умолчанию — `configs` рядом с приложением; его можно задать при запуске. Автозапуск включается пользователем.

**PL-03. Состав.** Постоянно работающая часть с иконкой в трее обеспечивает показ меню, работу с конфигурацией в памяти и управление через MCP. Для ручного редактирования предусмотрен отдельный визуальный редактор. Точные границы процессов и транспорт MCP определяются при техническом проектировании.

**PL-04. Библиотека автоматизации.** LibreAutomate/Au — кандидат для проверки прототипом. Её окончательный выбор и UI-фреймворк пока не закреплены. Документ не объявляет исследованные API проверенной реализацией приложения.

**PL-05. Языковые ресурсы и интерфейс.** В portable-сборку включаются английские (`en-US`) и русские (`ru-RU`) спутниковые ресурсы; папки ресурсов других языков в итоговой поставке отсутствуют. Язык интерфейса обоих приложений выбирается в меню трея независимо от конфигурации, по умолчанию — английский. Для открытого редактора требуется повторный запуск; пользовательские данные не переводятся.

## 2. Дерево меню и вызов

**MN-01. Единое дерево.** Пункты имеют три вида: группа, действие, разделитель. Подменю являются группами единого дерева. Жёсткое ограничение вложенности пятью уровнями не вводится.

**MN-02. Показ.** Компактное меню с иконками и каскадными подменю открывается у курсора. Доступно управление мышью и клавиатурой.

**MN-03. Горячие клавиши.** Основное меню вызывается горячей клавишей. Кроме того, любому пункту, кроме разделителя, можно назначить своё сочетание:

- Для действия оно непосредственно выполняет действие без открытия меню.
- Для группы открывает только её подменю, без предварительного показа основного и родительских меню.
- Ограничения по числу дочерних пунктов группы нет.
- Для прямого вызова используются те же пункты дерева; копии не создаются.

**MN-04. Конфликты.** Дубликаты сочетаний внутри конфигурации запрещены. Если сочетание недоступно из-за другого приложения, проблема явно показывается; соответствующий пункт остаётся доступен через меню.

**TR-01. Трей.** Левый клик открывает редактор или переключает на него. Правый — служебное меню: открыть редактор, перезагрузить конфигурацию, переключить автозапуск, выйти из приложения.

## 3. Действия

| ID | Действие | Параметры и поведение |
| --- | --- | --- |
| AC-01 | Открыть папку | Путь к папке. В первой версии открывается новое окно Проводника. Другие режимы открытия относятся к возможному развитию. |
| AC-02 | Запустить программу | Исполняемый файл, аргументы, рабочая папка. Параметры допускают согласованные переменные контекста. |
| AC-03 | Запустить скрипт | BAT, CMD или PS1, аргументы и рабочая папка. Для PS1 при добавлении предпочитается установленный PowerShell 7, иначе Windows PowerShell; выбранный интерпретатор виден и редактируется. По умолчанию консоль видима, доступен скрытый запуск. Системная execution policy автоматически не меняется. |
| AC-04 | Отправить сочетание | Одно настроенное сочетание отправляется в окно, активное до вызова меню/действия, после возврата ему фокуса. Если окно недоступно, показать причину и не отправлять сочетание в другое окно. |
| AC-05 | Копировать объекты | Выделенные файлы и папки Проводника копируются в настроенную папку назначения. |
| AC-06 | Переместить объекты | Выделенные файлы и папки Проводника перемещаются в настроенную папку назначения. |

**AC-07. Файловые конфликты.** При совпадении имён пользователь выбирает замену, пропуск или отмену. При отсутствии выделения сообщается, что копировать/перемещать нечего.

**AC-08. Длительные операции.** Показываются ход выполнения и возможность отмены. При частичном сбое сообщаются успешные, пропущенные и неудачные объекты. Уже завершённые перемещения автоматически не откатываются.

## 4. Контекст и параметры

**CT-01. Исходное окружение.** Исходное окно и выделенные файлы/папки запоминаются при вызове меню или прямом вызове действия. Выбор пункта не должен подменять их более поздним выделением или окном самого меню.

**CT-02. Выделенный текст — условная возможность.** Желателен в первой версии, если получение текста не требует сложной реализации. Целевые приложения: браузер, Codex и Telegram. Универсальная поддержка всех приложений не является обязательством первой версии. Конкретный браузер и проверенная матрица приложений определяются перед техническим экспериментом.

**CT-03. Момент получения текста.** Текст получают из исходного окна после выбора действия, которому он нужен; это согласованное исключение из правила снимка при открытии меню. При прямом вызове такого действия получение выполняется при вызове.

**CT-04. Буфер обмена.** Допустимо временное копирование с последующим восстановлением буфера, если проверка покажет приемлемое поведение. Копирование не выполняется при обычном открытии меню ради потенциальной потребности. Существующий буфер сам по себе не считается текущим выделением.

**CT-05. Недоступный контекст.** Если нет необходимых данных или исходное окно недоступно, показать причину и не выполнять действие. Нельзя молча подменять отсутствующее выделение содержимым буфера.

**CT-06. Переменные.** Начальный набор: выделенный текст при включении этой возможности, выбранные пути файлов/папок, текущая папка Проводника. Преобразования: имя файла, расширение, родительская папка, кодирование текста для URL.

**CT-07. Шаблонизация.** Встроенные возможности ограничены подстановками и небольшим набором преобразований. Сложная логика выносится во внешние BAT/CMD/PS1. Рядом с полем параметра предусмотрен выбор переменной. Синтаксис и библиотека шаблонизации выбираются при проектировании.

**CT-08. Список путей.** При передаче списка файлов программе каждый путь становится отдельным аргументом. Список не объединяется неявно в одну строку команды.

## 5. Визуальный редактор

**ED-01. Основной экран.** Две связанные панели: дерево меню и свойства выделенного пункта. Имя, иконка и поля выбранного действия редактируются непосредственно в панели свойств. Основной сценарий не требует визарда.

**ED-02. Создание перетаскиванием.** EXE, BAT, CMD, PS1, LNK или папка перетаскиваются в выбранное место дерева. Создаётся черновик пункта с иконкой по умолчанию; имя, иконка и параметры доступны для настройки. Порядок и вложенность видны при выборе места вставки. Поддерживается перетаскивание нескольких объектов за один раз.

**ED-03. Импорт LNK.** Из ярлыка извлекаются цель запуска, аргументы и рабочая папка. Значения становятся редактируемыми свойствами самостоятельного пункта. Если ярлык разобрать не удалось, сообщить об ошибке.

**ED-04. Импорт папки и частичные ошибки.** Папка создаёт действие открытия папки. Если отдельный объект не поддерживается или не обработан, остальные допустимые объекты всё равно добавляются; проблемные перечисляются в сообщении.

**ED-05. Операции.** Создание групп и разделителей, перемещение перетаскиванием, дублирование, удаление, отмена и повтор правок до применения.

**ED-06. Иконки.** Нажатие на иконку открывает поиск по комплекту Boxicons; доступны также выбор из EXE/DLL/ICO или изображения и возврат к иконке Проводника. Иконка отображается с предпросмотром. Выбранные изображения и ICO копируются в папку ресурсов приложения. Иконки из EXE/DLL хранятся как ссылки на исходные файлы. При добавлении программы или скрипта сами запускаемые файлы не копируются.

**ED-07. Закрытие с правками.** Предложить сохранить изменения, отбросить их или отменить закрытие редактора.

## 6. Конфигурация, применение и восстановление

**CF-01. Каталог конфигураций.** Все конфигурации хранятся в одном каталоге. При запуске каталог выбирается по параметру командной строки, иначе по переменной окружения, иначе используется `configs` рядом с исполняемым файлом. Параметр имеет приоритет. Приложение, редактор и MCP используют один каталог. Отсутствующий каталог создаётся; при ошибке доступа сообщается причина. Внешние изменения не подхватываются автоматически.

**CF-02. Корень и имя.** У конфигурации есть явный корень с обязательным именем, настройками и дочерними пунктами дерева. Имена уникальны в каталоге без учёта регистра и хранятся в конфигурации; имя файла техническое. Корень виден в дереве редактора, его выбор открывает свойства конфигурации и настройки. Корень нельзя удалить или переместить; он не отображается в меню и панели запуска. Переименование применяется вместе с черновиком.

**CF-02a. Управление.** Над деревом находится список-переключатель доступных конфигураций; отдельной кнопки выбора конфигураций нет. Выбор загружает черновик, действующая конфигурация меняется при сохранении. Действия создания пунктов доступны в контекстном меню узлов дерева. При изменении имени и сохранении пользователь выбирает: перезаписать исходную конфигурацию с новым именем или сохранить копию; отдельной команды «Сохранить как» нет. При переходе с несохранёнными правками предложить сохранить, отбросить или отменить.

**CF-02c. Удаление.** В свойствах корня есть кнопка удаления действующей конфигурации с подтверждением. Другие конфигурации можно удалить после переключения на них и применения. После успешного удаления активируется первая оставшаяся по алфавиту конфигурация; если других нет, создаётся и активируется пустая дефолтная. Ошибка операции не должна приводить к потере действующей конфигурации. Проверки, обнаружение конфликтов и бэкапы при сохранении сохраняются.

**CF-02b. Миграция.** При обнаружении прежней активной конфигурации вне нового каталога предложить скопировать её туда с деревом и настройками и назначить явное имя. Исходный файл и прежние данные выбора не удаляются и не перезаписываются. Старый формат должен читаться и переводиться в новую модель при сохранении.

**CF-03. Проверка.** Ошибки структуры, настроек и сочетаний блокируют применение. Незавершённые действия и шаги, включая пустые обязательные параметры, допускается сохранить; параметры и доступность путей проверяются при выполнении соответствующего шага, а причина ошибки показывается пользователю. Действие без шагов сообщает об ошибке при вызове.

**CF-04. Ошибка применения.** При ошибке проверки, создания бэкапа или записи изменения не применяются. Существующий файл и действующее меню не заменяются, причина возвращается пользователю или агенту.

**CF-05. Бэкапы и загрузка.** Хранятся 10 последних бэкапов. Выбранная конфигурация открывается как черновик; активация выполняется при применении.

**CF-06. Некорректный файл.** Сообщить, какой файл содержит проблему, и предложить исправить его либо создать дефолтную конфигурацию. Автоматического отката к последней рабочей версии нет. Дефолт — пустое пользовательское дерево с доступом к редактору из трея. Его создание — явный выбор с сохранением копии проблемного файла.

**CF-07. Независимые черновики.** Редактор и агент имеют отдельные черновики от известной версии конфигурации. Устаревший черновик нельзя молча применить поверх более свежей версии.

**CF-08. Разрешение конфликта.** Автоматическое слияние не требуется. Пользователь может загрузить актуальную конфигурацию; устаревший черновик нельзя применить или сохранить как копию без разрешения конфликта.

## 7. Управление агентом

**MC-01. Полномочия MCP.** Чтение конфигурации, создание и изменение пунктов/групп, перемещение, удаление, проверка и общее применение.

**MC-02. Самостоятельное применение.** Агент сам вызывает применение с бэкапом; подтверждение в редакторе не требуется. Правила проверки и защиты от конфликта действуют и для агента.

**MC-03. Граница.** Запуск пользовательских действий через MCP не входит в первую версию.

## 8. Исключения и развитие

- Поиск по меню не нужен и не планируется.
- Импорта и миграции из Quick Access Popup не будет.
- Полноценного встроенного скриптового языка в первой версии нет.
- Последовательности сочетаний клавиш не входят в первую версию.
- Отдельная модель «альтернативного меню» заменена общими действиями с переменными контекста.
- Интеграции с Mirabox N1, Elgato и Ulanzi D100H — возможное развитие. Реализация внешнего API и адаптеров не входит в первую версию.
- Дополнительные способы открытия папок относятся к возможному развитию.

## 10. Следующий этап

Продуктовые вопросы трёх раундов закрыты. До реализации предстоит техническое проектирование:

1. Макет двухпанельного редактора и выбор UI-фреймворка.
2. Проверка Au в самостоятельном приложении, поставки её native-компонентов, горячих клавиш, фокуса и выделения Проводника.
3. Проверка именно нового окна Проводника, а не повторного использования существующего.
4. Эксперимент с выделенным текстом в целевых приложениях и решение о включении условной возможности в первую версию.
5. JSON-схема, версии черновиков, контракт команд, транспорт MCP и конкретный синтаксис шаблонов.

Документационные основания для экспериментов: [LibreAutomate/Au](research-libreautomate.md), [Windows API и границы процессов](research-windows-menu-platform.md). Эти исследования не заменяют проверку работающего приложения. Начало реализации отдельно не поручалось.

## Уточнение от 23 октября 2026: настройки и плотность редактора

- Глобальные сочетания, положение панели и размер шрифта входят в конфигурацию и редактируются в свойствах её корня. Настройки доступны при выборе корня в редакторе.
- Изменения настроек сохраняются сразу. Занятое сочетание отклоняется с сохранением прежнего рабочего назначения. Размер шрифта — от 10 до 24, проверка через «Показать меню».
- Существующее глобальное сочетание переносится при отсутствии файла настроек. Импорт, Undo/Redo и применение дерева не меняют настройки. Конфликты сочетаний пунктов проверяются против актуальных настроек при применении.
- У редактора уменьшены отступы, удалены крупные заголовки панелей, оставлены подзаголовки; глобальное сочетание удалено из панели дерева, перезагрузка доступна через «Файл».
