# Иконки ContexWin

По умолчанию пункт использует значок Windows Shell, как в Explorer. Для нового ярлыка сохраняется путь исходного `.lnk`, чтобы учитывать его собственную иконку. Существующие пункты с пустым `IconPath` получают значок по пути действия. Значок из PNG/JPG/BMP/ICO или ресурса EXE/DLL можно назначить отдельно; кнопка «Как в Explorer» убирает назначение.

## Включено: Microsoft Fluent System Icons

Небольшая подборка из 38 PNG (19 назначений, контурный и заполненный стили): папки, документы, приложения, настройки, веб, код, почта, календарь, камера, изображения, музыка, видео, игры, поиск, сохранение, удаление, копирование, буфер обмена, домашняя страница. Голубой цвет читается на светлом и тёмном фоне. Это универсальные значки назначений, а не логотипы конкретных программ.

- Источник: https://github.com/microsoft/fluentui-system-icons
- Лицензия MIT: https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE
- В дистрибутиве: `icon-packs/Fluent/`, включая текст лицензии, SVG-оригиналы и `sources.json` с адресами источников.
- Изменения: экспорт в PNG 48×48, цвет `#60a5fa`.
- Выбор: свойства пункта → «Выбрать…». Первое открытие показывает папку `icon-packs/Fluent/`. После выбора файла запоминается его исходная папка, включая выбор из другого места; она восстанавливается после перезапуска. Если папка удалена, снова открывается комплект иконок. Настройка хранится в `icon-picker-folder.txt` рядом с приложением. Отмена выбора не меняет сохранённую папку.

## Дополнительные варианты

1. **Tabler Icons** — альтернативный набор универсальных контурных значков. MIT допускает включение в дистрибутив при сохранении уведомления и лицензии. Источник: https://github.com/tabler/tabler-icons ; лицензия: https://github.com/tabler/tabler-icons/blob/main/LICENSE . Не включён: текущий минимум уже покрывает Fluent.
2. **Simple Icons** — логотипы приложений, сервисов и брендов. Лицензия проекта CC0 не означает одинаковых прав на все логотипы: авторы требуют учитывать индивидуальные лицензии и правила брендов. Источник: https://github.com/simple-icons/simple-icons ; условия: https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md . Предлагается для отдельной проверенной подборки, а не для включения всего каталога.

Для установленных программ точнее использовать их собственные значки через Explorer. Это также не требует включать чужие логотипы в дистрибутив.
