# Иконки m3nuxa

По умолчанию пункт использует значок Windows Shell, как в Explorer. Для нового ярлыка сохраняется путь исходного `.lnk`, чтобы учитывать его собственную иконку. Существующие пункты с пустым `IconPath` получают значок по пути действия. Значок из PNG/JPG/BMP/ICO или ресурса EXE/DLL можно назначить отдельно; кнопка «Как в Explorer» убирает назначение.

## Основной комплект: Boxicons v2

В комплект входят 1634 значка Boxicons 2.1.4 — тот же набор, который по умолчанию используется в Trilium. Нажмите на иконку в свойствах пункта, чтобы открыть каталог, выбрать цвет из палитры или задать произвольный цвет и найти значок по английскому имени. Вверху окна слева видно компактное превью выбранной иконки, справа — одинаковые по размеру кнопки выбора файла и значка Explorer. Название и цвет доступны в подсказке превью. Палитра цветов помещается в одну строку без горизонтальной прокрутки; кнопка «…» открывает выбор произвольного цвета. Выбор в каталоге и смена цвета обновляют превью; окно остаётся открытым. Кнопка «Выбрать» переносит назначение в черновик редактора, «Отмена» или Escape отбрасывают правки окна. Для смены только цвета повторно выбирать иконку не требуется. Цвет доступен для встроенных иконок Boxicons. Выбор файла и возврат к значку Explorer также сначала обновляют превью и требуют подтверждения; изображение копируется в ресурсы только после подтверждения. Назначение сохраняется как относительный путь внутри portable-папки. Команды выбора файла и «Как в Explorer» находятся в этом же диалоге.

- Источник: https://github.com/atisawd/boxicons, версия 2.1.4; лицензия MIT включена в `icon-packs/Boxicons/LICENSE.txt`.
- Изменения: глифы шрифта преобразованы в PNG 48×48 голубого цвета, с полем до 3 пикселей по большей стороне скриптом `tools/generate-boxicons.py`.

## Дополнительная подборка: Microsoft Fluent System Icons

Небольшая подборка из 38 PNG (19 назначений, контурный и заполненный стили): папки, документы, приложения, настройки, веб, код, почта, календарь, камера, изображения, музыка, видео, игры, поиск, сохранение, удаление, копирование, буфер обмена, домашняя страница. Голубой цвет читается на светлом и тёмном фоне. Это универсальные значки назначений, а не логотипы конкретных программ.

- Источник: https://github.com/microsoft/fluentui-system-icons
- Лицензия MIT: https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE
- В дистрибутиве: `icon-packs/Fluent/`, включая текст лицензии, SVG-оригиналы и `sources.json` с адресами источников.
- Изменения: экспорт в PNG 48×48, цвет `#60a5fa`.
- Выбор: нажмите иконку рядом с названием пункта и выберите «Из файла…». Первое открытие показывает папку `icon-packs/Fluent/`. После выбора файла запоминается его исходная папка, включая выбор из другого места; она восстанавливается после перезапуска. Если папка удалена, снова открывается комплект иконок. Настройка хранится в `icon-picker-folder.txt` рядом с приложением. Отмена выбора не меняет сохранённую папку.

## Дополнительные варианты

1. **Tabler Icons** — альтернативный набор универсальных контурных значков. MIT допускает включение в дистрибутив при сохранении уведомления и лицензии. Источник: https://github.com/tabler/tabler-icons ; лицензия: https://github.com/tabler/tabler-icons/blob/main/LICENSE . Не включён: основной комплект покрывает Boxicons.
2. **Simple Icons** — логотипы приложений, сервисов и брендов. Лицензия проекта CC0 не означает одинаковых прав на все логотипы: авторы требуют учитывать индивидуальные лицензии и правила брендов. Источник: https://github.com/simple-icons/simple-icons ; условия: https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md . Предлагается для отдельной проверенной подборки, а не для включения всего каталога.

Для установленных программ точнее использовать их собственные значки через Explorer. Это также не требует включать чужие логотипы в дистрибутив.

## Значки приложения

Значки окна редактора и области уведомлений созданы на основе Microsoft Fluent System Icons (MIT, лицензия включена в `icon-packs/Fluent/LICENSE.txt`): использованы значки Document и Apps, добавлены цветная подложка и карандаш для редактора. ICO содержат варианты для разных размеров экрана.
